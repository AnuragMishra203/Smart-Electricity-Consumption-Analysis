# ⚡ Smart Electricity Consumption Analysis

## 📌 Project Overview

This project analyzes household electricity consumption data to identify usage patterns, clean real-world data, and generate meaningful visualizations using Python.

The project demonstrates a complete data analysis workflow, including data loading, preprocessing, exploratory data analysis (EDA), and visualization.

---

## 🎯 Objectives

- Load a real-world electricity consumption dataset.
- Clean and preprocess the data.
- Handle missing values.
- Convert data into appropriate data types.
- Analyze electricity consumption patterns.
- Create visualizations to gain useful insights.

---

## 📂 Dataset

**Dataset Name:** Individual Household Electric Power Consumption

**Source:** UCI Machine Learning Repository (or Kaggle)

The dataset contains minute-level household electricity consumption measurements collected over several years.
